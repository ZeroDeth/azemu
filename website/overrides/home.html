Your Azure stack,running on your laptop.

azemu is an open-source local Azure emulator. Point the unmodified azurerm provider at it and your Terraform or OpenTofu stack applies and destroys end to end — no subscription, no account, no network, no bill.

Quick start View source

MIT licensed · no paid tier · no telemetry · no account to create

terminal
# start the emulator + Azurite sidecar
$ docker compose up -d --build
# trust the local cert for this shell
$ export SSL_CERT_FILE=$PWD/.azemu/cert-bundle.pem
# apply a real stack against it
$ terraform -chdir=examples/terraform init
$ terraform -chdir=examples/terraform apply -auto-approve
Apply complete! Resources: 14 added, 0 changed, 0 destroyed.

Why it works

The provider never knows the difference.

01

Real ARM endpoints, not mocks

azemu serves the standard Azure management endpoints over TLS. The stock azurerm provider runs unmodified — swap terraform for tofu and nothing else changes.

02

Fidelity you can audit

Every supported resource is listed in a public parity matrix with its support depth, and every row links to the test that proves it. No coverage claims you have to take on trust — read the row, read the test.

03

Data planes, not just metadata

Blobs land in Azurite, Key Vault actually signs, the CDN endpoint actually serves content. You can test the read path, not just watch state files change.

04

A portal for the emulator

A local web console ships inside the binary: three views over your emulated subscription and a live stream of every ARM request the provider makes. When an apply fails, you can see why.

Where it's going

Coverage grows from what people actually need.

The resources above work end to end today. The aim is to cover more of Azure so more teams can test their stack locally, and to keep raising fidelity on what already exists — but the order is set by demand, not by a roadmap written in a vacuum.
